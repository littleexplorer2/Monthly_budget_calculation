数据管理

行程、预算标准与计算结果保存在项目 data/ 目录。关闭最后一个网页时会自动完整保存；上传时同步预算/行程状态与用户默认标准，汇率缓存按需重新拉取。

上传包含 data/app-state.json 与 data/defaults.json，不包含 data/rates/；需要预先配置远程仓库和 Git 登录。
