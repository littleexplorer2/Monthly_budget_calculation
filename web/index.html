数据管理

行程、订阅、资产、预算标准与计算结果只保存在本机项目 data/ 目录。程序不会自动上传任何用户数据；只有你点击下方按钮并再次确认后，才会同步应用状态与用户默认标准。

显式确认的上传包含 data/app-state.json（含订阅与资产）及 data/defaults.json，不包含 data/rates/；需要预先配置远程仓库和 Git 登录。
