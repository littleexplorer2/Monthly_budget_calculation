# 多币种预算计算器（Web 版）

本地网页版互动界面，通过本地端口在浏览器中运行，默认地址 <http://127.0.0.1:8123>；启动后会自动打开浏览器。
（早期的命令行入口已删除，现在只有 Web 版。）

## 计算规则

### 月度预算

| 预算类型 | 规则 |
| --- | --- |
| **可变预算（定居）** | `每日预算额 × 当月在此地定居天数`，每一天按**当日汇率**折算人民币后求和 |
| **固定预算** | 每个区域（内地/境外）的**各币种月额 × 当月平均汇率**，每个区域**每月只计算一次** |
| **额外预算** | **CNY / USD / HKD 月额 × 当月平均汇率**，**每月只计算一次**（规则与固定预算相同） |
| **旅游/旅居预算** | `每日预算 × 旅游天数`（逐日汇率折算）**+ 单次预算 × 当月平均汇率**（每个旅居地点**每月只算一次**） |

月度外币汇率保持原有算法：Yahoo Finance 同一交易日同时有 `Open` 与 `Close` 时取
`(Open + Close) / 2`；再对齐到所选月份的每个自然日。周末、节假日等缺失日使用最近可用值，
当前月尚未发生的日期使用本月至截至日的日均汇率估算。CNY 对人民币的汇率恒为 1。

默认预算标准以运行时页面和 `GET /api/meta` 返回值为准：`functions.py` 提供出厂配置；若存在
`data/defaults.json` 且文件校验通过，则使用用户在「⚙ 默认预算标准」中保存的覆盖值；损坏文件会在页面明确提示，
不会被当作空配置覆盖。README 不重复维护具体金额。

### 全年预算

- 「全年总览」中的全年预算与月度预算相互独立。当前年份的截至日（`as_of`）是运行当天；历史年份的截至日是该年 12 月 31 日。
- 每种外币只取该年 1 月 1 日至截至日（含）Yahoo Finance 返回的**实际交易日 `Close`**；周末、节假日、未来日期及其他非交易日不补值，也不使用月度的 `(Open + Close) / 2` 或日历日填充逻辑。
- 年平均汇率是该币种上述有效 `Close` 观测值的算术平均。页面同时显示样本数量和实际覆盖到的最新收盘日。
- 每种货币的全年当地金额乘以该币种年平均汇率，得到折合人民币金额；各币种折合人民币金额相加即全年预算。金额必须是非负有限数字。
- 某币种汇率获取失败时，金额为 0 不影响其他币种；金额非 0 时拒绝生成不完整的全年总额。

## 功能

1. **本次计算选项面板（高亮）**：顶部**居住区域选择（内地/境外）**与**预算标准确认**合并为
   一个高亮的「⚙ 本次计算选项」面板；固定预算表**只显示当前选中区域**对应的标准；
   计算前必须勾选「我已确认以上预算标准无误」——修改标准、恢复默认、切换区域或新建标准后需重新确认。
2. **旅居开关与选择**：「**是否包含旅居**」默认关闭；**只有勾选后**才显示旅居地点
   选择下拉，以及**当月**预算标准页的「旅居预算标准」栏目（栏目内**只显示已勾选的旅居地点**）。
   可勾选/全选/清空本次计算包含的旅居地点（如仅选曼谷则上海、台北的旅居费用不计入），
   计算时未选中的旅居行程会给出明确提示。（顶栏「⚙ 默认预算标准」弹窗不受此开关限制，见第 4 条。）
3. **新建预算标准**：当某月需要的**旅居地点、定居地点或固定预算币种**不在默认标准中时，
   可点击卡片底部「＋ 新建」添加（地点名称 + 币种代码 + 每日/单次或月额），
   自动出现在地点选择 chips、旅居下拉、日历与计算中；页面上方表格里的新建标准**默认按月单独保存**。
   在顶栏「⚙ 默认预算标准」弹窗里新建的地点/币种则属于默认标准，点「**保存默认标准**」后生效
   （币种汇率按 币种CNY=X 从 Yahoo Finance 获取）。
4. **两个互不影响的区域**：当月标准直接显示在「预算标准」页，服务器默认标准放在顶栏的弹窗里。
   - **当月预算标准**（「预算标准」页，随月份切换，标题显示当前年月）：金额改动只影响本月，
     写入 `data/app-state.json` 的当月覆盖项；提供「**恢复默认**」（本月改回当前默认值）和
     「**恢复出厂默认**」（删除 `data/defaults.json`，恢复 `functions.py` 出厂值，**不改动本月数值**）。
   - **服务器默认预算标准**（顶栏「**⚙ 默认预算标准**」按钮，就在「计算预算」左边，点击弹出界面）：
     弹窗内直接编辑默认值，点「**保存默认标准**」写入 `data/defaults.json`（新月份使用；保存不会改动当月），
     或点「**放弃修改**」丢弃草稿；✕ 或点击遮罩关闭，有未保存改动时会先询问。
   - 弹窗顶部有「**显示所有默认预算**」开关（默认**不勾选**）：
     - **不勾选**：只显示本月对应的部分——本月居住区域（内地/境外）的固定预算 + 本月行程里出现过的旅居地点；
     - **勾选**：内地与境外固定预算**逐组显示**（每组各有「＋ 新建币种」，新建归该组），并列出**全部**旅居地点；
     - 该开关只是**展示过滤**：不写任何文件、不改动当月数值，也不影响计算；
     - 因此旅居预算栏目在弹窗里**始终可见**（不像当月面板那样依赖「包含旅居」开关），关掉开关也能编辑默认旅居标准。
   - **保存默认标准不会改动本月预算**：已保存月份的数值同样保持原样（保存前会把其它月份固化为完整快照）。
     若想让本月立刻使用新的默认值，请在当月区域点「恢复默认」。
5. **「与默认值不同」标记**：两个界面里任何与服务器默认值不同的行都会显示
   **「与默认值不同 · 默认 N」标记**（弹窗内显示「与已保存默认值不同」，并带「**还原**」按钮，
   把该项恢复为已保存的默认值）。当月表格的标记不加按钮，避免误改另一侧。
6. **行程管理（按地点索引）**：选择定居/旅居地点 → 在**月历**上点击两个日期快速选定时间段
   （支持连续多段、手动日期输入、重叠自动去重），行程按月分别保存。
7. **汇率走势**：当月各币种兑人民币每日汇率**按币种拆分、每币种一张独立折线图**
   （各自独立的纵轴比例尺，避免 USD≈7.2、HKD≈0.92、THB≈0.19 等不同量级互相压平，
   导致走势看起来像水平直线）+ 月度统计表（起始/期末/均值/最低/最高），数据来自 Yahoo Finance。
   进入该页时优先使用本地缓存；点击 **「重新拉取」** 会跳过内存与磁盘缓存，
   向 Yahoo Finance 重新下载当前请求的币种，并更新 `data/rates/YYYY-MM.json` 中对应币种的数据。月中计算时，
   尚未发生日期统一使用**本月截至当天的日均汇率**估算，不再沿用运行当天的单日汇率；
   这些未来估算值不会写入磁盘缓存，避免下次运行时被误当成历史实际汇率。
8. **全年总览**：这是独立于月度预算页的年度信息页，左侧按年份计算全年预算，右侧比较已计算过的各月总预算。
   选择年份后，页面加载该年年初至截至日的实际交易日 `Close` 年平均汇率；在各币种输入框填写全年当地金额，
   点击「**计算全年预算**」即可查看各币种折合人民币金额和全年合计。「**刷新收盘汇率**」会跳过年度进程内缓存重新获取数据。
   当前年按运行当天截止，历史年按 12 月 31 日截止；全年输入和结果按年份独立保存，不会改动月度行程、标准或结果。
   修改全年金额或手动刷新全年收盘汇率后，旧总额会立即失效并持久化为待重算状态；重新打开页面也不会把旧总额恢复为当前结果。
   若强制刷新只取得部分币种或完全失败，页面会保留上一次完整有效结果并给出警告，不会把它误标为已用不完整行情重算。
   月度预算输入变更后，旧结果仍保留供追溯，但会明确标记为过期，并在重新计算前退出各月比较，避免把旧结果误当成当前结果。
9. 结果页展示：顶部总额卡片下方是**三张明细表**——**每日预算明细**（通栏，含当地每日预算额、
   天数、当地合计、折合人民币）、**固定预算明细**（含旅居一次性费用）与**额外预算明细**
   （额外预算与固定预算**分开两张表**并列显示）；每张表的合计显示在**卡片标题右侧**，
   顶部胶囊同步显示 **可变 / 固定 / 额外**，三者相加正好等于本月总预算。
   金额列只写数字（币种单独一列，不再每格重复币种代码），居住区域显示中文「内地 / 境外」；
   窄屏（≤980px）自动变单列，表格放不下时在卡片内横向滚动而不挤压列。
10. **自动保存与快速恢复**：行程、预算标准修改、月度计算结果、全年金额与全年结果写入项目 `data/app-state.json`，
   月度汇率写入 `data/rates/`，默认标准写入 `data/defaults.json`；年度原始行情不写入磁盘。浏览器 localStorage 只作本机缓存。
   换电脑或换浏览器后，只要仓库里的 `data/` 同步过来，就能读到全部数据。
   关闭页面时做最后一次保存并停止服务、释放端口；Safari 等浏览器漏发关闭事件时，服务器会在标签页失联约 20 秒后兜底退出。
   重新打开网页自动恢复到上次的月份。
   顶部**切换月份时同步切换**该月的行程安排、预算标准、汇率数据、计算结果，以及内地/境外与旅居勾选。
11. **关闭页面自动停止服务**：关闭最后一个浏览器页面后，先把本标签页尚未保存的状态变更写入 `data/app-state.json`，
   成功后再退出进程并释放端口；保存失败时服务保持运行，避免静默丢失数据。页面每 5 秒刷新一次服务器租约，
   即使 Safari 没有送达 `pagehide` / `sendBeacon`，失联租约也会在约 20 秒后被清理并触发退出。进入浏览器前进/后退缓存时不会立即注销标签页，
   普通刷新和多标签页按各自生命周期注册，不会误杀服务。不同标签页按月份/年份键合并；若同时修改同一键，旧基线写入会被拒绝并提示刷新，
   不会用旧快照覆盖另一页的新数据。可用 `--no-autoshutdown` 关闭自动停止。
12. **网络检测**：打开网页时自动检测能否从 Yahoo Finance 下载汇率数据；若不可达，
    页面顶部显示醒目横幅提示「**网络异常，请打开VPN后重试**」，并可一键重新检测；
    计算/汇率拉取失败时横幅也会同步点亮。
13. **汇率缓存**：月度已下载的汇率数据自动保存到服务端 `data/rates/YYYY-MM.json`；
    再次访问该月时**先查内存缓存 → 磁盘缓存，都没有才下载**，避免重复请求 Yahoo Finance。
    需要最新行情时，在汇率页点击 **「重新拉取」**（`GET /api/rates?refresh=true`）可强制重新下载并更新所请求币种。
    新版磁盘缓存会校验月初至应有截止日的每个自然日和值；缺少中间日期或出现非法值会按损坏缓存处理并重新下载。
    年度 `Close` 使用与月度分离的进程内缓存，不写入月度磁盘缓存；「刷新收盘汇率」可跳过该缓存。
14. **数据管理与远程备份**：顶栏「🗂 数据管理」弹窗展示全年输入/结果，以及各月份已保存的行程、标准修改、
    计算结果和汇率缓存，支持**按月份删除**、**清空全部保存数据**及**保存并上传全部数据**。
    上传会先强制保存页面状态，再把整个 `data/` 的新增、修改与删除单独提交并推送到当前分支；
    需要仓库已配置 Git 远程和登录。程序不会自动拉取或解决冲突，以免覆盖远端数据。
15. **地点差异化配色**：每个定居/旅居地点分配互不相同的醒目颜色；地点选择 chips、
    日历上已添加行程的日期、行程清单分组均按地点颜色标注，一目了然。

## 快速开始

项目使用根目录下独立的 `.venv`。用 VS Code / Codex 打开 `每月预算.code-workspace` 时，
工作区会默认选择这个环境；首次使用仍需按当前系统创建环境并安装依赖。

```powershell
# Windows PowerShell（Python 3.10+）
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python main_requirement.py
python main_web.py
```

```bash
# macOS / Linux（Python 3.10+）
python3 -m venv .venv
source .venv/bin/activate
python main_requirement.py
python main_web.py
```

启动后会自动打开浏览器，默认地址为 <http://127.0.0.1:8123>。

`main_requirement.py` 会使用当前虚拟环境的 Python 解释器，将
`requirements.txt` 中的全部依赖安装或升级到该环境；后续依赖清单有变化时，
重新运行此脚本即可。

```bash

# 可选参数
python main_web.py --port 9000            # 自定义端口
python main_web.py --no-open              # 启动后不自动打开浏览器
python main_web.py --no-autoshutdown      # 关闭页面时不自动停止服务（常驻，需手动 Ctrl+C）
python main_web.py --autoshutdown-grace 5   # 关闭页面后延迟停止（秒；默认 0，立即释放端口）
```

换电脑使用：先 `git pull` 取得最新 `data/`，再启动程序。行程、内地/境外、旅居勾选、
每月标准修改、月度结果、全年金额与全年结果都以 `data/app-state.json` 为准；打开页面**不会**用空的浏览器
缓存（默认「内地」）覆盖仓库里已保存的境外选项。改完数据后可在「数据管理」点击
「保存并上传全部数据」，也可在本项目目录中手动把整个 `data/` 提交推送：

```bash
git add -A -- data/
git commit -m "保存月度与全年预算数据"
git push
```

其它电脑 `git pull` 后即可读到完整预算数据。在任一电脑上改完数据后同样把 `data/` 提交推送。

## 接口一览

| 接口 | 说明 |
| --- | --- |
| `GET /api/meta` | 返回当前生效的默认标准、地点、区域、币种元数据及 `defaults_revision` |
| `GET /api/state` | 读取 `data/app-state.json`（月度数据及 `annualBudgetsByYear` / `annualResultsByYear`） |
| `PUT /api/state` | 按月份/年份键合并写入月度及年度状态；页面携带所改键的 `baseValues`、`tabId`、递增 `sequence` 做原子并发保护，`replace=true` 仅用于清空全部 |

`annualResultsByYear` 保存紧凑的全年摘要与明细。原始年度汇率序列、月度 `rates` / `rates_dict`
和年度 `series` 都不会写入状态文件；缺少年度字段的旧状态按空对象兼容。

## 设计与工程说明

- **单一计算层**：月度 `calculate_travel_budget` 与年度 `calculate_annual_budget` 都在 `functions.py`；
  Web 层负责请求校验、汇率获取和调用，不复制计算公式。月度计算可通过
  `standards_override` / `rates_dict` 传入本次预算标准与已缓存汇率；
  `resolve_standards` 支持通过 `custom_locations` 新建地点、为区域新增固定币种、
  以及额外预算（CNY/USD/HKD），并返回地点注册表用于行程校验与币种映射。
  用户默认标准保存在 `data/defaults.json`，启动时覆盖模块级字典，不改写 `functions.py` 源码。
- **年度管线独立**：年度下载器只提取实际交易日 `Close`，不调用月度 `(Open + Close) / 2`
  与日历日填充逻辑；年度行情使用独立进程内缓存，不写入 `data/rates/`。年度输入和紧凑结果
  分别写入 `annualBudgetsByYear` / `annualResultsByYear`，原始行情序列不进入应用状态。
- **明细拆分**：`calculate_travel_budget` 把额外预算单独放进 `extra_details`，
  `fixed_details` 只保留固定预算与旅居一次性费用，summary 另给「额外预算合计(人民币)」；
  额外预算**仍计入**「固定费用合计(人民币)」与总预算，因此数值与旧存档不受影响。
  结果页据此排成三张卡片：每日预算明细（通栏）+ 固定预算明细 / 额外预算明细（并排），
  合计写在卡片标题右侧（`#daily-details-total` / `#fixed-details-total` / `#extra-details-total`），
  顶部胶囊的可变 + 固定 + 额外必须正好等于本月总预算；读取只有 `fixed_details` 的旧存档时，
  前端按行类型（`type == "额外预算"` / `location == "Extra"`）兜底拆分，不会重复计算。
- **默认标准与当月解耦**：预算标准页的当月表格只写 `data/app-state.json` 的当月覆盖；
  顶栏「⚙ 默认预算标准」弹窗编辑的默认标准只写 `data/defaults.json`（弹窗位于预算标准页内，
  复用该页的输入事件委托）。保存默认标准前先把当前月与其它已有月份固化为完整快照并确认状态写盘成功，
  且**不改写当月数值**；当月要改用新默认值需显式点「恢复默认」。
  输入写哪一份数据按输入框所在位置判断（是否在 `.defaults-editor` 内），两侧互不影响。
- **跨设备数据**：行程、每月选项、标准覆盖、月度结果、全年输入与全年结果保存在 `data/app-state.json`，
  汇率在 `data/rates/`，默认标准在 `data/defaults.json`。磁盘写入对 Windows 与 macOS
  （含 iCloud、OneDrive）使用临时文件 + fsync + replace，失败则直接覆盖。
  浏览器 localStorage 只作缓存；读取服务器成功后仅镜像服务器状态，不把缓存反向合并。
  服务器状态读取完成前或读取失败后保持只读，避免无基线的旧缓存覆盖磁盘。多标签写入只提交相对各自读取基线发生变化的键；
  普通写入全有或全无，同一月份或年份被另一页先修改时返回 `409 STATE_CONFLICT`，页面保留本机缓存并要求刷新。
  默认标准也通过 `defaults_revision` 做整份快照的乐观并发校验，避免另一标签页的保存或恢复被覆盖。
- **三级汇率缓存**：进程内缓存（1 小时 TTL，线程安全、同一币种并发只下载一次）→
  磁盘缓存（`data/rates/YYYY-MM.json`，原子写入）→ 仅在两者都缺失时才下载并回写。
  月度汇率页「重新拉取」走 `refresh=true`：清除该月进程内缓存、跳过磁盘读取，重新下载并更新所请求币种。
- **兼容性**：汇率数据兼容新版 yfinance（MultiIndex 列、带时区索引）与旧版（扁平列）。
- **健壮性**：请求参数全量校验（月份范围、日期格式、不跨月、地点已知、金额非负）；
  删除类接口先全量校验再执行，避免部分成功；错误统一为 `{error: {code, message}}`
  中文提示（400/409/422/502/500）。
- **安全性**：默认仅绑定 `127.0.0.1`，仅供本地个人使用。

## 风险与注意事项

1. **汇率依赖外网**：汇率来自 Yahoo Finance，无网络或 Yahoo 不可达时汇率/计算会失败。
   月度算法会为周末、节假日和当前月未来日期补齐估算值；年度算法只统计实际交易日 `Close`，
   不补非交易日。两者均仅供预算参考。
   「重新拉取」必须能访问 Yahoo Finance，失败时不会改写已有的磁盘缓存。
2. **数据存储**：行程、每月预算标准修改、月度结果、全年输入与全年结果保存在 `data/app-state.json`，
   汇率在 `data/rates/`，默认标准在 `data/defaults.json`。这些文件纳入 git。
   打开页面只读取服务器文件；仅当读取失败时才回退本机缓存，并保持只读直至刷新成功，不会把无可信基线的本机缓存回写服务器。
   换电脑（含 macOS）后 `git pull` 即可读到完整数据。「数据管理」删除会同时改磁盘文件。
3. **行程唯一归属**：同一地点重叠日期段自动去重（只计一次），计算响应中的
   `warnings` 会提示重复天数；同一天若被分配给不同地点则拒绝计算并提示冲突日期。
4. **行程不得跨月**：每段行程日期必须位于所选月份内。
5. **固定预算换算**：固定费用与旅居一次性费用按当月平均汇率折算（与原程序一致）。
