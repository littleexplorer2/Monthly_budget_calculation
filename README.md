# 多币种预算计算器（Web 版）

本地网页版互动界面，通过本地端口在浏览器中运行，默认地址 <http://127.0.0.1:8123>；启动后会自动打开浏览器。
（早期的命令行入口已删除，现在只有 Web 版。）

## 计算规则

### 月度预算

| 预算类型 | 规则 |
| --- | --- |
| **可变预算（定居）** | `每日预算额 × 当月在此地定居天数`，每一天按**当日汇率**折算人民币后求和 |
| **固定预算（订阅）** | 当月勾选订阅项目按 CNY / HKD / USD 汇总：月付使用填入金额，年付使用 `金额 ÷ 12`；各币种月均合计再乘当月平均汇率，每月只计算一次 |
| **旅游/旅居预算** | `每日预算 × 旅游天数`（逐日汇率折算）**+ 单次预算 × 当月平均汇率**（每个旅居地点**每月只算一次**） |

月度外币汇率保持原有算法：Yahoo Finance 同一交易日同时有 `Open` 与 `Close` 时取
`(Open + Close) / 2`；再对齐到所选月份的每个自然日。周末、节假日等缺失日使用最近可用值，
当前月尚未发生的日期使用本月至截至日的日均汇率估算。CNY 对人民币的汇率恒为 1。
若在**当前月份的 1 日**计算时 Yahoo 尚未提供本月行情，应用会自动改用**上一个自然月各币种的月平均汇率**，
并在计算结果警告中标明回退来源；其它日期或历史月份仍会明确报告行情错误，不会静默套用旧数据。

所有预算标准、年度金额和汇率统计中的币种统一按 **CNY、HKD、USD** 优先，其余币种按三个字母代码的
字母顺序显示。

默认预算标准以运行时页面和 `GET /api/meta` 返回值为准：`core/standards/builtin.py` 提供出厂配置；若存在
`data/defaults.json` 且文件校验通过，则使用用户在「⚙ 默认预算标准」中保存的覆盖值；损坏文件会在页面明确提示，
不会被当作空配置覆盖。README 不重复维护具体金额。

### 全年预算

- 「全年总览」中的全年预算与月度预算相互独立。当前年份的截至日（`as_of`）是运行当天；历史年份的截至日是该年 12 月 31 日。
- 全年预算输入固定为 **CNY、HKD、USD** 三种货币；旧状态里保存的其它币种不会显示或参与新一轮计算。
- 每种外币只取该年 1 月 1 日至截至日（含）Yahoo Finance 返回的**实际交易日 `Close`**；周末、节假日、未来日期及其他非交易日不补值，也不使用月度的 `(Open + Close) / 2` 或日历日填充逻辑。
- 年平均汇率是该币种上述有效 `Close` 观测值的算术平均。页面同时显示样本数量和实际覆盖到的最新收盘日。
- 每种货币的全年当地金额乘以该币种年平均汇率，得到折合人民币金额；各币种折合人民币金额相加即全年预算。金额必须是非负有限数字。
- 某币种汇率获取失败时，金额为 0 不影响其他币种；金额非 0 时拒绝生成不完整的全年总额。

## 功能

1. **Spendee 风格浅色双层导航**：页面采用浅灰蓝背景、蓝灰文字、白色低阴影卡片与可读的深绿色主操作；
   固定在视口顶部的白色全局栏保留原有悬浮位置和响应式排版。品牌、
   「**预算计算** / **数据面板**」、月份切换和数据管理统一放在全局栏。其下的上下文栏把
   **居住区域 / 包含旅居**放在左侧，把预算计算的**订阅管理 / 预算标准 / 行程安排 / 计算结果**子导航放在中间，
   把「**⚙ 默认预算标准** / **更新预算**」放在右侧。固定预算表只读显示订阅月均汇总，
   页面不再设置“确认当月预算标准”门禁。
2. **订阅管理是固定预算的唯一来源**：订阅管理是预算标准之前的独立功能分区，CNY / HKD / USD
   三栏并排展示，每栏各有本币种的新增按钮；本月卡片可删除和编辑名称、每月/每年周期及金额，币种由所在栏固定，
   不在卡片内改换。每个项目的“计入默认”与“计入当月预算”是两个独立勾选框：取消前者表示从本月之后永久取消，
   本月与更早月份保留，已有和新建的后续月份都会移除；后者只决定该项目是否进入当前月固定预算。
   「⚙ 默认预算标准」弹窗的订阅目录负责长期默认项目定义
   以及没有最近月份快照时的初始值。卡片的“适用预算”下拉可分别勾选“对内地预算使用”和“对海外预算使用”；
   旧卡片默认两者都勾选，至少保留一个区域。只适用于某一区域的项目不会出现在另一区域月份视图，也不会计入
   另一区域的固定预算。
   升级后首次打开该弹窗时，旧月份已有订阅及原“计入默认”状态会先进入未保存草稿，确认保存后才成为
   正式默认订阅目录。
   每个月保存独立订阅快照；默认项目在新月份重新使用默认目录金额，某个月单独改动金额只保存在该月。永久取消
   会清理取消月之后已经存在的月份，并用取消标记阻止相同项目 ID 被默认目录重新加入，不改动取消月和更早月份。
   月付金额直接计入，年付金额除以 12 后计入当月；固定预算的 CNY、HKD、USD 三项只读，避免再维护一套手工金额。旧状态没有订阅字段时仍可读取，
   但旧手工固定/额外预算不会自动伪装成订阅，历史月份由用户逐月补录。
3. **旅居开关与选择**：「**是否包含旅居**」默认关闭；**只有勾选后**才显示旅居地点
   选择下拉，以及**当月**预算标准页的「旅居预算标准」栏目（栏目内**只显示已勾选的旅居地点**）。
   可勾选/全选/清空本次计算包含的旅居地点（如仅选曼谷则上海、台北的旅居费用不计入），
   计算时未选中的旅居行程会给出明确提示。（上下文栏「⚙ 默认预算标准」弹窗不受此开关限制，见第 4 条。）
4. **新建每日/旅居预算标准**：当某月需要的**旅居地点或定居地点**不在默认标准中时，
   可点击卡片底部「＋ 新建」添加（地点名称 + 币种代码 + 每日/单次金额），
   自动出现在地点选择 chips、旅居下拉、日历与计算中；页面上方表格里的新建标准**默认按月单独保存**。
   在上下文栏「⚙ 默认预算标准」弹窗里新建的地点/币种则属于默认标准，点「**保存默认配置**」后生效
   （一般币种按 `币种CNY=X` 从 Yahoo Finance 获取）。
5. **两个互不影响的区域**：当月标准直接显示在「预算标准」页，服务器默认标准放在上下文栏的弹窗里。
   - **当月预算标准**（「预算标准」页，随月份切换，标题显示当前年月）：金额改动只影响本月，
     写入 `data/app-state.json` 的当月覆盖项；提供「**恢复默认**」（本月改回当前默认值）和
     「**恢复出厂默认**」（删除 `data/defaults.json`，恢复 `core/standards/builtin.py` 出厂值，**不改动本月数值**）。
   - **服务器默认配置**（上下文栏右侧「**⚙ 默认预算标准**」按钮，点击弹出界面）：
      弹窗明确分为“每日与旅居预算标准”和“订阅项目管理”两部分；“＋ 新建定居地点”位于前者标题右侧，
      后者只显示仍勾选“计入默认”的项目，并维护未来月份使用的标准金额。点「**保存默认配置**」
      写入 `data/defaults.json`（新月份使用；保存不会改动当月），
     或点「**放弃修改**」丢弃草稿；✕ 或点击遮罩关闭，有未保存改动时会先询问。
   - 弹窗顶部有「**显示全部旅居预算**」开关（默认**不勾选**）：
     - **不勾选**：显示全部每日预算及本月行程里出现过的旅居地点；
     - **勾选**：显示全部每日预算及**全部**旅居地点；
     - 该开关只是**展示过滤**：不写任何文件、不改动当月数值，也不影响计算；
     - 因此旅居预算栏目在弹窗里**始终可见**（不像当月面板那样依赖「包含旅居」开关），关掉开关也能编辑默认旅居标准。
   - **保存默认配置不会改动本月预算**：已保存月份的数值同样保持原样（保存前会把其它月份固化为完整快照）。
     若想让本月立刻使用新的默认值，请在当月区域点「恢复默认」。
6. **「与默认值不同」标记**：两个界面里任何与服务器默认值不同的行都会显示
   **「与默认值不同 · 默认 N」标记**（弹窗内显示「与已保存默认值不同」，并带「**还原**」按钮，
   把该项恢复为已保存的默认值）。当月表格的标记不加按钮，避免误改另一侧。
7. **行程管理（按地点索引）**：选择定居/旅居地点 → 在**月历**上点击两个日期快速选定时间段
   （支持连续多段、手动日期输入、重叠自动去重），行程按月分别保存。切换到尚无任何保存数据的月份时，
   页面先询问「**是否要新增XXXX年XX月的预算数据？**」；取消后保留原月份且不写入空记录，确认后才创建目标月数据。
8. **数据面板**：数据面板只保留「**年度总览 / 资产管理**」两个分区，不再提供月度汇率走势图或
   独立月度汇率接口。启动后和手动点击「**更新预算**」时，计算用例自动取得本次实际需要的币种并缓存；
   CNY 始终使用人民币恒等汇率 1，不请求任何人民币替代行情。月中计算时，尚未发生日期统一使用
   **本月截至当天的日均汇率**估算；这些未来估算值不会写入磁盘缓存，避免下次运行时被误当成历史实际汇率。
9. **全年总览**：这是数据面板的第一分区，左侧按年份计算全年预算，右侧以折线图比较已计算过的各月总预算；
   月份、总预算、区域和是否旅居只在鼠标悬停对应月份点时显示，不再另列明细表。
   选择年份后，页面加载该年年初至截至日的实际交易日 `Close` 年平均汇率；全年输入只显示
   CNY、HKD、USD。程序启动和切换年度时自动取得年度行情并更新全年预算，同时保留「**更新全年预算**」手动按钮。
   当前年按运行当天截止，历史年按 12 月 31 日截止；全年输入和结果按年份独立保存，不会改动月度行程、标准或结果。
   修改全年金额或年度行情覆盖范围变化后，旧总额会立即失效并持久化为待重算状态；重新打开页面也不会把旧总额恢复为当前结果。
   若强制刷新只取得部分币种或完全失败，页面会保留上一次完整有效结果并给出警告，不会把它误标为已用不完整行情重算。
   月度预算输入变更后，旧结果仍保留供追溯，但会明确标记为过期，并在重新计算前退出各月比较，避免把旧结果误当成当前结果。
10. **资产管理**：数据面板新增独立“资产管理”分区。活期存款、定期存款和投资使用统一编号的三栏卡片布局，
    窄屏自动重排；各板块维护地点/机构、账户/项目、
   用途、币种和金额。顶部两张紧凑组合指标卡分别只展示“当前资产总额 + 相对计算基数”和
   “现金率 + 投资资产率 + 存款率”，后续指标空间保留在整行右侧而不放入卡片内部；其中存款率为
   “活期与定期 ÷ 当前资产”。币种结构将 CNY、HKD、USD 按固定顺序绘制在同一条堆叠占比条中，并随资产编辑实时重绘。
   计算基数可分别填写 CNY、HKD、USD，当期基数按同一组参考均值折合人民币后与资产总额比较；右侧 HKD/USD
   汇率只读卡片保持紧凑。CNY 汇率固定为 1，HKD 与 USD 自动使用截至当日
   最近 365 个自然日内 Yahoo Finance 实际交易日 `Close` 的算术平均；页面展示样本数和观测截止日，并可手动刷新。
   缺少外币行情时只显示已知部分并标记“待补汇率”，旧状态里的手填汇率不会作为回退值参与新换算。
11. **结果页展示**：顶部总额卡片下方是**两张明细表**——**每日预算明细**（通栏，含当地每日预算额、
   天数、当地合计、折合人民币）和**固定预算明细**（订阅月均固定预算及旅居一次性费用）；每张表的合计显示在
   **卡片标题右侧**，顶部胶囊同步显示 **可变 / 固定**，两者相加正好等于本月总预算。旧结果里的额外预算
   只作过期追溯提示，不会恢复为可编辑来源。
   金额列只写数字（币种单独一列，不再每格重复币种代码），居住区域显示中文「内地 / 境外」；
   窄屏（≤980px）自动变单列，表格放不下时在卡片内横向滚动而不挤压列。
12. **自动保存与快速恢复**：行程、订阅逐月快照、资产组合、预算标准修改、月度计算结果、全年金额与全年结果写入项目 `data/app-state.json`，
    月度汇率写入 `data/rates/`，默认预算与默认订阅写入 `data/defaults.json`；年度及资产最近一年原始行情不写入磁盘。浏览器 localStorage 只作本机缓存。
   换电脑或换浏览器后，只要仓库里的 `data/` 同步过来，就能读到全部数据。
   关闭页面时做最后一次保存并停止服务、释放端口；Safari 等浏览器漏发关闭事件时，服务器会在标签页失联约 20 秒后兜底退出。
   重新打开网页自动恢复到上次的月份并读取已保存数据；随后自动更新年度预算，并在当前月已有行程时自动更新月度预算，
   两者都保留手动更新按钮，自动过程不会强制切换当前页签。
   顶部**切换月份时同步切换**该月的行程安排、预算标准、订阅快照、计算结果，以及内地/境外与旅居勾选；
   没有数据的目标月份必须先确认新增。
13. **退出时建立不可覆盖备份**：关闭最后一个页面或以 Ctrl+C 正常停止服务时，程序先完成状态写入，再在
    `backups/` 下新建一个只追加快照，例如 `2026-11-01_14-15-16.123_UTC+0800_run-01234567/`。
    每个快照只复制 `data/app-state.json` 与 `data/defaults.json`，并附带文件大小、SHA-256 和创建原因清单；
    不复制可重建的 `data/rates/`。历史快照不覆盖、不删除，也没有恢复或计算读取接口；`backups/` 被 Git 忽略。
    自动退出时若备份失败，服务保持运行并记录错误，不会伪装成成功退出。
    升级后第一次正常保存若发现旧月份仍含手工 `fixed` / `extra` 覆盖，会先创建原因标记为
    `pre-subscription-fixed-migration` 的完整快照；备份失败则拒绝迁移写入。
14. **关闭页面自动停止服务**：关闭最后一个浏览器页面后，先把本标签页尚未保存的状态变更写入 `data/app-state.json`，
    成功并完成退出备份后再退出进程、释放端口；保存失败时服务保持运行，避免静默丢失数据。页面每 5 秒刷新一次服务器租约，
   即使 Safari 没有送达 `pagehide` / `sendBeacon`，失联租约也会在约 20 秒后被清理并触发退出。进入浏览器前进/后退缓存时不会立即注销标签页，
   普通刷新和多标签页按各自生命周期注册，不会误杀服务。不同标签页按月份/年份键合并；若同时修改同一键，旧基线写入会被拒绝并提示刷新，
    不会用旧快照覆盖另一页的新数据。可用 `--no-autoshutdown` 关闭自动停止。
15. **Yahoo 数据源检测**：打开网页时自动检测能否从 Yahoo Finance 下载汇率数据；探测墙钟上限覆盖
    yfinance 的主下载与备援请求。失败或超时只说明 Yahoo 本次请求不可用或响应慢，不会直接断言本机网络或 VPN
    故障；页面顶部显示具体提示并可一键重新检测。
    计算/汇率拉取失败时横幅也会同步点亮。
16. **汇率缓存**：计算月度预算时下载的汇率数据自动保存到服务端 `data/rates/YYYY-MM.json`；
    再次访问该月时**先查内存缓存 → 磁盘缓存，都没有才下载**，避免重复请求 Yahoo Finance。
    预算计算自动触发行情获取；前端不提供独立月度汇率拉取或展示入口。
    新版磁盘缓存会校验月初至应有截止日的每个自然日和值；缺少中间日期或出现非法值会按损坏缓存处理并重新下载。
    年度与资产最近 365 天的 `Close` 使用与月度分离的进程内缓存，不写入月度磁盘缓存。
17. **数据管理与远程备份**：全局栏「数据管理」弹窗展示资产组合、全年输入/结果，以及各月份已保存的订阅、行程、标准修改、
    计算结果和汇率缓存，支持**按月份删除**、**清空全部保存数据**及**保存并上传预算数据**。
    程序绝不会自动上传用户数据；只有用户当次点击上传并确认后，上传请求才携带显式确认标记。
    此时程序会先强制保存页面状态，再只提交并推送 `data/app-state.json`（预算、行程、计算状态）与
    `data/defaults.json`（用户默认标准）；`data/rates/` 是可重建缓存，不进入应用内上传提交。
    需要仓库已配置 Git 远程和登录。程序不会自动拉取或解决冲突，以免覆盖远端数据。
18. **地点差异化配色**：每个定居/旅居地点分配互不相同的醒目颜色；地点选择 chips、
    日历上已添加行程的日期、行程清单分组均按地点颜色标注，一目了然。

| --- | --- |
| `GET /api/meta` | 返回当前生效的默认预算、默认订阅目录、地点、区域、币种元数据及 `defaults_revision` |
| `GET /api/state` | 读取 `data/app-state.json`（月度数据、`subscriptionsByMonth`、`assetPortfoliosById` 及年度状态） |
| `PUT /api/state` | 按月份/年份/资产组合键合并写入状态；页面携带所改键的 `baseValues`、`tabId`、递增 `sequence` 做原子并发保护，`replace=true` 仅用于清空全部 |
| `POST /api/defaults` | 接收完整预算标准、默认订阅目录及 `base_revision`，写入 `data/defaults.json`；版本过期返回 `409 DEFAULTS_CONFLICT` |
| `POST /api/defaults/reset` | 接收 `base_revision`，删除已保存默认标准并恢复出厂值；版本过期返回 `409 DEFAULTS_CONFLICT` |

| `GET /api/asset-rates?currencies=HKD,USD` | 返回截至当日最近 365 天的实际交易日 `Close` 平均值、样本数与覆盖日期；`refresh=true` 强制刷新进程内缓存 |
| `POST /api/annual-budget` | 接收 `{year, amounts: {币种: 全年当地金额}}`，按实际 `Close` 年平均汇率返回逐币种人民币金额与全年合计 |
| `POST /api/calculate` | 只为预算实际币种自动获取行情并执行计算；CNY 恒为 1；返回 `rate_source` 来源元数据，当前月 1 日无行情时使用上月均值并返回警告（支持 `standards_override`、`include_travel`、`travel_locations`） |
| `GET /api/network-check` | 检测 Yahoo Finance 连通性（页面打开时自动调用） |
| `POST /api/tabs/register` / `heartbeat` / `unregister` | 浏览器标签页注册、租约续期与注销（驱动关闭页面自动停止及 Safari 丢事件兜底） |
| `GET /api/data/rates` | 列出磁盘上已保存的汇率月份 |
| `POST /api/data/rates/delete` | 删除指定月份的汇率缓存（先全量校验再执行） |
| `POST /api/data/upload` | 仅接受用户当次明确确认的 `{user_confirmed: true}`；只提交 `data/app-state.json` 与 `data/defaults.json` 并推送到已配置的 Git 远程当前分支，不提交汇率缓存 |
| `GET /api/health` | 健康检查 |

年度状态按年份保存在 `data/app-state.json`：`annualBudgetsByYear` 保存全年当地金额；新计算只读取
CNY、HKD、USD，并兼容忽略旧状态中的其它币种。
`annualResultsByYear` 保存紧凑的全年摘要与明细。原始年度汇率序列、月度 `rates` / `rates_dict`
和年度 `series` 都不会写入状态文件；缺少年度字段的旧状态按空对象兼容。
`subscriptionsByMonth` 以 `YYYY-MM` 保存订阅项目快照；每月对象的 `items` 是该月项目，`retiredIds` 是只向后累计的
永久取消项目 ID，旧快照缺少该字段时按空数组兼容。默认订阅目录保存在 `data/defaults.json` 的 `subscriptions`
字段；每项的 `appliesTo: {Mainland, Overseas}` 分别控制两种区域预算，旧数据缺失时默认两者为真；
`assetPortfoliosById.current` 保存三币种 `calculationBase: {CNY, HKD, USD}`、
兼容保留的旧参考汇率字段和资产条目。新资产换算只使用 `/api/asset-rates` 返回的最近 365 天均值；
旧版数值型 `calculationBase` 按纯 CNY 单向规范，缺少这些字段的旧状态同样按空对象兼容。
旧 `overridesByMonth.*.fixed` / `extra` 在读取时忽略，下一次有意义的状态写入会在迁移前备份后统一移除；
订阅快照、每日/旅居覆盖、行程和历史结果保留。没有新预算模型标记的历史月度结果会显示为过期，需重新计算。

## 设计与工程说明

- **单一计算层**：月度 `calculate_travel_budget` 与年度 `calculate_annual_budget` 位于 `core/budget/`。
  `application/budget/` 负责请求用例、标准快照、行程展开和汇率获取，不复制公式；底层计算
  不读取默认值文件，也不主动下载汇率。`core/standards/` 负责自定义地点、固定币种与额外预算
  的标准解析；`application/defaults/` 管理 `data/defaults.json`，不改写出厂配置。
  外部旧代码仍可通过 `functions.py` 调用原公开函数，新功能应使用所属模块的公开入口。
- **年度管线独立**：年度下载器只提取实际交易日 `Close`，不调用月度 `(Open + Close) / 2`
  与日历日填充逻辑；年度行情使用独立进程内缓存，不写入 `data/rates/`。年度输入和紧凑结果
  分别写入 `annualBudgetsByYear` / `annualResultsByYear`，原始行情序列不进入应用状态。
- **资产参考汇率独立区间**：资产管理复用实际交易日 `Close` 下载与校验基础设施，但区间固定为
  截至当日最近 365 个自然日，不复用全年预算的年初至今区间。前端只消费应用层汇率接口；
  旧状态中的手填汇率字段原样保留但不进入换算。
- **订阅固定预算单一来源**：前端订阅模块按内地/海外适用范围筛选勾选项目并换算为月均金额，把两个区域各自的
  CNY / HKD / USD 汇总作为显式 `fixed` 标准传给既有月度公式；月份覆盖只保存每日与旅居标准，不保存派生 `fixed` 或旧 `extra`。
  新月份从默认目录恢复标准金额；当月金额覆盖不向后传播。永久取消通过后续月份 `retiredIds` 墓碑阻止同 ID 复活，
  同时保留取消月及更早月份的完整项目快照。
  结果页只展示每日预算与固定预算两张卡片。底层仍兼容读取旧结果中的 `extra_details`，但前端只把它标作
  过期追溯信息，不再提供编辑入口或新计算来源。
- **默认配置与当月解耦**：预算标准页的当月表格只写 `data/app-state.json` 的当月覆盖；
  独立顶层弹窗中的预算金额标准与默认订阅目录只写 `data/defaults.json`。保存默认配置前先把当前月与
  其它已有月份固化为完整快照并确认状态写盘成功，
  且**不改写当月数值**；当月要改用新默认值需显式点「恢复默认」。
  当月与默认配置使用各自事件边界，两侧互不影响。
- **跨设备数据**：行程、订阅快照、资产组合、每月选项、标准覆盖、月度结果、全年输入与全年结果保存在 `data/app-state.json`，
  汇率在 `data/rates/`，默认标准在 `data/defaults.json`。磁盘写入对 Windows 与 macOS
  （含 iCloud、OneDrive）使用临时文件 + fsync + replace，失败则直接覆盖。
  浏览器 localStorage 只作缓存；读取服务器成功后仅镜像服务器状态，不把缓存反向合并。
  服务器状态读取完成前或读取失败后保持只读，避免无基线的旧缓存覆盖磁盘。多标签写入只提交相对各自读取基线发生变化的键；
  普通写入全有或全无，同一月份或年份被另一页先修改时返回 `409 STATE_CONFLICT`，页面保留本机缓存并要求刷新。
  默认标准也通过 `defaults_revision` 做整份快照的乐观并发校验，避免另一标签页的保存或恢复被覆盖。
- **备份只追加**：`application/backups/` 在正常退出及固定预算数据迁移前读取两个权威用户 JSON 并新建时间戳快照；
  预算、汇率、状态读取和 API 均不导入或扫描 `backups/`。快照先写临时目录，清单完成后再以目录重命名发布，
  不提供覆盖、删除或恢复历史备份的生产接口。
- **月度行情自动获取与三级缓存**：启动自动更新或点击「更新预算」时，应用层按实际所需币种获取行情；进程内缓存
  （1 小时 TTL，线程安全、同一币种并发只下载一次）→
  磁盘缓存（`data/rates/YYYY-MM.json`，原子写入）→ 仅在两者都缺失时才下载并回写。
  若当前月 1 日尚无行情，应用层用上一个自然月的有效序列计算各币种均值，再显式传入底层公式。
  应用层只为预算实际币种取数，CNY 始终使用恒等汇率 1；月度计算响应不携带展示行情，前端也不另发
  月度汇率请求。
- **兼容性**：汇率数据兼容新版 yfinance（MultiIndex 列、带时区索引）与旧版（扁平列）。
- **健壮性**：请求参数全量校验（月份范围、日期格式、不跨月、地点已知、金额非负）；
  删除类接口先全量校验再执行，避免部分成功；错误统一为 `{error: {code, message}}`
  中文提示（400/409/422/502/500）。
- **安全性**：默认仅绑定 `127.0.0.1`，仅供本地个人使用。

## 风险与注意事项

1. **汇率依赖外网**：汇率来自 Yahoo Finance，无网络或 Yahoo 不可达时汇率/计算会失败。
   月度算法会为周末、节假日和当前月未来日期补齐估算值；年度算法只统计实际交易日 `Close`，
   不补非交易日。两者均仅供预算参考。
   自动拉取必须能访问 Yahoo Finance；当前月 1 日可按上述规则回退，其它拉取失败不会改写已有的磁盘缓存。
2. **数据存储**：行程、订阅逐月快照、资产组合、每月预算标准修改、月度结果、全年输入与全年结果保存在 `data/app-state.json`，
   汇率缓存位于 `data/rates/`，默认预算与默认订阅在 `data/defaults.json`。这些用户数据默认只留在本机，
   不会因普通保存、启动、退出、提交或推送而自动上传；只有用户显式点击并确认“保存并上传预算数据”时，
   应用内上传才纳入状态文件和默认配置，不纳入可重建的汇率缓存；新生成的月度缓存由 `.gitignore` 忽略。
   打开页面只读取服务器文件；仅当读取失败时才回退本机缓存，并保持只读直至刷新成功，不会把无可信基线的本机缓存回写服务器。
   `backups/` 是本机退出快照且被 Git 忽略，不会随上传同步，也不会被预算程序读取。
   换电脑（含 macOS）后 `git pull` 即可读到已上传的权威数据。「数据管理」删除会同时改磁盘文件。
3. **行程唯一归属**：同一地点重叠日期段自动去重（只计一次），计算响应中的
   `warnings` 会提示重复天数；同一天若被分配给不同地点则拒绝计算并提示冲突日期。
4. **行程不得跨月**：每段行程日期必须位于所选月份内。
5. **固定预算换算**：订阅月付按原金额、年付按金额除以 12 汇总；所得固定费用与旅居一次性费用按当月平均汇率折算。
